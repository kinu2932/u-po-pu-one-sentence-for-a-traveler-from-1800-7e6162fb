Entry for the [One Sentence for a Traveler from 1800](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb) bounty on make.fun.

`main.py` writes a single sentence (174 characters) to `/output/entry.txt`,
explaining the modern internet to someone arriving from the year 1800 using
only things they would already know: a road, a post office, a library, and a
market square.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
